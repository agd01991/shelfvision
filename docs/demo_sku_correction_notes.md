# Коррекция SKU-галереи в демонстрационном интерфейсе

Ветка `demo-defense-interface-phase1` содержит визуальный сценарий экспертной корректировки автоматически сформированной SKU-галереи.

Основной пользовательский сценарий:

1. выбрать целевой SKU;
2. визуально проверить текущие эталоны;
3. отметить эталоны из других автоматически созданных SKU, которые относятся к целевому товару;
4. записать операции в `06_manual_gallery/manual_cluster_edits.csv`;
5. собрать ручную SKU-галерею;
6. пересчитать идентификацию query-объектов с ручной галереей;
7. сравнить показатели до и после.

Исходные результаты эксперимента не изменяются. Все ручные операции сохраняются отдельно, а повторная идентификация использует уже готовый `03_query_inference/predictions.json` без повторного запуска детектора.

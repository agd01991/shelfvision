# Сравнение с открытыми проектами с похожим названием

В открытом доступе существуют проекты с похожими названиями `ShelfVision` / `shelfVision`. Совпадение названия не означает совпадение реализации или заимствование программного решения. В финальных материалах ВКР название не рассматривается как научная новизна или уникальный бренд; результатом работы является реализованный программный комплекс и экспериментально проверенная последовательность обработки полочной сцены.

## Ближайший по названию проект: KirbysGit/shelfVision

Проект KirbysGit/shelfVision описывается как учебный проект по детекции товаров на полках. Его основной фокус — задача object detection, PyTorch-реализация, ResNet50 + FPN, anchors и сравнение с YOLOv5.

Данная ВКР отличается по постановке задачи и реализации:

1. Рассматривается не только локализация объектов, но и полный контур gallery/query для SKU-сопоставления.
2. Из найденных объектов формируются вырезанные товарные фрагменты.
3. Автоматически строится демонстрационная SKU-галерея.
4. Эталоны галереи проходят дедупликацию.
5. Для каждого проверяемого объекта сохраняются `top-k` ближайших кандидатов.
6. Для спорных случаев используется `margin` между лучшим и ближайшим альтернативным SKU.
7. Введены статусы `matched`, `matched_uncertain`, `unknown`.
8. Результаты сохраняются в CSV/JSON/MD и визуализируются.
9. Предусмотрена экспертная ручная корректировка галереи и результатов идентификации.

## Общий вывод

Сходство с открытыми проектами ограничивается общей предметной областью компьютерного зрения для розничных полок и типовыми терминами `shelf` / `vision`. Кодовая структура, экспериментальная логика, контур SKU-сопоставления, отчётные артефакты и демонстрационный интерфейс ВКР являются самостоятельной реализацией.

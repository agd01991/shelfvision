# Данные проекта

Датасеты и веса моделей не включаются в репозиторий из-за размера и лицензионных ограничений.

Для ВКР использовалась подготовленная выборка изображений полочных сцен на основе SKU-110K. Итоговый демонстрационный контур работает с разбиением на две части:

- gallery: 160 изображений для формирования демонстрационной SKU-галереи;
- query: 140 изображений для проверки SKU-сопоставления;
- итоговая проверка: 300 изображений, 200 демонстрационных SKU, 1360 эталонных изображений.

Рабочий путь к данным указывается в `config/vkr_final.yaml` и/или `config/shelfvision.yaml`.

Пример структуры локальных данных:

```text
D:/1Diplom/data/raw/d2s_full/images/
D:/1Diplom/sku_gallery_full_vkr_final/
D:/1Diplom/shelfvision_results/full_photo_identification_vkr_final/
```

В репозиторий добавляется только этот файл-описание. Каталог `data/**` исключен из версионирования в `.gitignore`.
